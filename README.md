# 🗺️ MAP-CI V6

> Cartographie • GPS • EXIF • Live — dans ton terminal Termux

## ✨ Fonctionnalités

- 🔎 Recherche de ville (Nominatim)
- 🗺️ Carte (OSM, Google Maps, MapSCII ASCII)
- 📷 Analyse EXIF + géolocalisation de photos
- 🌦️ Météo actuelle + 7 jours + qualité de l'air
- 📍 Position IP
- 🧭 Distance + itinéraire voiture
- 🛰️ Position ISS en direct
- 🌐 Fuseaux horaires
- 🏔️ Altitude
- 🏛️ Points d'intérêt proches
- 🌕 Phase de la Lune
- 🚀 Lancements spatiaux
- 📋 QR code de position
- 📤 Export GPX / KML
- 📊 Tableau de bord
- 🎮 Jeux (quiz, chasse au trésor…)
